## 日本語

### 収集する情報

本アプリは、**利用者の個人情報を収集しません**。

本アプリは、端末にインストールされているアプリについて以下の情報を読み取り、画面に表示します。

- アプリ名、パッケージ名、バージョン、アイコン
- インストール日、最終更新日
- アプリの容量（本体・ユーザーデータ・キャッシュ）
- 最終起動日、前面表示時間
- アプリが宣言している権限、および付与済みかどうか

これらはすべて Android が提供する標準の API から取得したもので、**端末内でのみ利用されます**。

### 情報の保存

利用者が本アプリ内で作成した情報（タグ、お気に入り、非表示の設定、メモ）および
上記の使用状況の日次記録は、**端末内のデータベースにのみ保存されます**。

### 第三者への提供・外部送信

**一切ありません。**

本アプリは Android のインターネット権限（`android.permission.INTERNET`）を宣言していないため、
技術的に、いかなるデータも外部へ送信することができません。

広告 SDK、アクセス解析 SDK、クラッシュレポート SDK のいずれも組み込んでいません。

### 使用する権限

| 権限 | 用途 | 任意/必須 |
|---|---|---|
| 使用状況へのアクセス（`PACKAGE_USAGE_STATS`） | 最終起動日・使用時間・アプリ容量の表示 | **任意**。許可しなくても一覧・検索・タグ・権限確認は利用できます |
| アプリの削除リクエスト（`REQUEST_DELETE_PACKAGES`） | アンインストール画面を開くため | 必須。実際の削除は必ず Android の確認画面を経由します |

### データの削除

本アプリをアンインストールすると、本アプリが保存したすべてのデータが端末から削除されます。

## English

### Information we collect

This app **does not collect any personal information**.

The app reads the following information about the apps installed on your device and displays it on screen:

- App name, package name, version, icon
- Install date, last update date
- App size (app, user data, cache)
- Last time used, foreground time
- Permissions the app declares, and whether they are granted

All of this comes from standard Android APIs and is used **on your device only**.

### Storage

Information you create in the app (tags, favourites, hidden apps, notes) and the daily usage
snapshots are stored **only in a local database on your device**.

### Sharing and transmission

**None.**

The app does not declare Android's internet permission (`android.permission.INTERNET`),
so it is technically incapable of transmitting any data anywhere.

It contains no advertising, analytics, or crash-reporting SDKs.

### Permissions used

| Permission | Purpose | Required? |
|---|---|---|
| Usage access (`PACKAGE_USAGE_STATS`) | Showing last-used dates, screen time and app sizes | **Optional.** The list, search, tags and permission views work without it |
| `REQUEST_DELETE_PACKAGES` | Opening Android's uninstall screen | Required. Android always shows its own confirmation |

### Deleting your data

Uninstalling the app removes all data it stored on your device.
